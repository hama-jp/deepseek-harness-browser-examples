# 検証記録

呼び出し側が、モデルの作業用ブラウザとは別のChrome 153.0.8010.47で操作を確認しました。公開用に固定したHTMLのSHA-256は `conditions.json`、配布ファイル全体はルートの `SHA256SUMS` にあります。画像はアプリを実際に表示して撮影しています。

## Lattice

通常の入力・クリック・キー操作による166項目を確認しました。計算、依存するセルの更新、書式、コピーと相対参照の調整、Undo/Redo、再読込、JSON/CSVの保存と読込、エラー値、無効な読込ファイルからの復帰を含みます。New/Clear/Example/Openを取り消したときに表を保持することも確認しています。

数式バーとセル内入力の両方で、マウス・矢印によるセル参照、ドラッグ・Shift+矢印による範囲、F2の文字カーソル切替を確認しました。試用中に報告された「確定後に参照範囲の色が残る」不具合を修正し、Enter/Tab/Esc/別欄への移動後に参照色が消え、その後のセル移動でも復活しないことを追加検証しました。

390×844のタッチ画面では縦横スクロール、セル編集、確認ダイアログを確認しています。IMEは合成compositionイベントによる回帰検査です。実OSの日本語入力や実機スマートフォンの全挙動は検証範囲に含めていません。

## Neon Velocity

37項目のUI・ゲーム操作検査に加え、実ウィンドウのフォーカスを別のウィンドウに移した場合の8項目を確認しました。発射、左右フリッパー、得点、3球終了、再スタート、一時停止、ミュート、キーボードと画面ボタンを含みます。

4段階の発射強度を各30秒動かし、盤面外への逸脱、無効な座標、静止して抜けられない状態が生じないことを確認しました。左ガイド付近に球が挟まる状態は再現後に修正しています。左右フリッパー付近から上方への戻りも座標の観測で確認しました。実際の出力音声には波形があり、ミュート時には出力が止まります。

ゲームは独自の簡易物理実装です。現実のピンボール機の挙動を測定して合わせたものではありません。音声検査は出力レベルによるもので、聴感の評価ではありません。フォーカス検査を、非表示タブの実機検証と同一視していません。

## Aquascape / Sakura Pagoda

水槽26項目、五重塔22項目を確認しました。PC・390×844の描画、一時停止と再開、動きを減らす設定での初期停止と明示的な再生、44pxのボタン、ブラウザの拡大、WebGLが使えない場合の案内を含みます。停止中のシーン中央の画素が2.7秒間変わらないことを比較し、PC・スマホ・夜景・代替表示のスクリーンショットも目視しました。

停止中に画面サイズを変えても描画が残ること、水槽のスマホ見出しが重ならないこと、キーボードで餌を追加でき、Pause操作では餌が増えないことも確認しています。状態を書き換えて合格させる操作は行わず、餌の個数などは読み取り専用で観測しています。

非表示から復帰する処理はソースで確認しました。非表示タブへの切替を実ブラウザで再現した試験の合格とはしていません。

## 共通の範囲

HTMLは実行時の外部サービスなしで確認しています。各3DアプリにはThree.jsのMITライセンス全文を含めています。同梱ソースから再ビルドしたHTMLは、検査済みHTMLとバイト単位で一致しました。水槽の再ビルドには、元の固定済み依存関係を使用しています。これは制作事例の確認記録であり、網羅的な品質保証やモデル間の比較スコアではありません。

デスクトップの検証環境はLinuxのChromeです。モバイルはブラウザのタッチ・画面サイズのエミュレーションであり、全OS・ブラウザ・GPU・実機端末での動作を保証するものではありません。表計算はXLSXやExcelの全機能を実装していません。残したい表はJSONとして保存してください。
